# Technical Stack - PHM Universal Translator

## Core Language
- **Python 3.10+**: Main orchestration and logic.

## Audio Processing
- **Librosa**: Signal processing and feature extraction (spectrograms).
- **SoundDevice**: Real-time audio capture.
- **NumPy**: Mathematical operations and signal manipulation.

## Speech-to-Text (STT)
- **Faster-Whisper**: Local offline transcription (PT-BR).

## User Interface (UI)
- **Flet**: Modern, responsive UI with Sci-Fi aesthetic.

## Database
- **SQLite3**: Local indexing of languages, audio files, and history.
