# Technology Stack

## Programming Languages
- Python - 3.10+ - Main language for all components.

## Frameworks
- PyTorch - Deep Learning framework for the Siamese Network.
- Librosa - Audio feature extraction.
- Faster-Whisper - Local speech-to-text processing.
- Flet (Planned) - Future frontend UI framework.

## Infrastructure
- Modal.com - Serverless cloud GPU provisioner for fast AI training.

## Build Tools
- pip - Package management (requirements.txt).

## Testing Tools
- pytest - Main test runner framework.
